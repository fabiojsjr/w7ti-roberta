# Funcionalidades — Roberta Attorre

## Objetivo

Apresentar uma página de pré-lançamento elegante enquanto o site definitivo está em desenvolvimento.

## Funcionalidades visíveis

1. Identidade **Roberta Attorre** em destaque.
2. Mensagem bilíngue: **Em breve / Coming soon**.
3. Imagem editorial responsiva, adaptada a telas grandes e celulares.
4. Atalho para o portfólio da W7 Tecnologia.
5. Ano do rodapé atualizado automaticamente pelo navegador.
6. Animações de entrada suaves, desativadas quando o visitante prefere movimento reduzido.

## SEO e compartilhamento

- Título e descrição próprios.
- URL canônica apontando para `https://robertaattorre.com/`.
- Metadados Open Graph para compartilhamento.
- Texto alternativo na imagem principal.

## Métricas

A página carrega o módulo central de analytics da W7 (`G-8XQ8YJQX01`), permitindo acompanhar acessos no Google Analytics junto aos demais projetos do portfólio.

## Infraestrutura

- Conteúdo estático, sem banco de dados ou dados pessoais.
- Publicação no Tomcat compartilhado sob `/robertaattorre/`.
- Acesso pelos hosts `roberta.w7ti.com`, `robertaattorre.com` e `www.robertaattorre.com`.
- HTTPS terminado no Application Load Balancer da AWS.
